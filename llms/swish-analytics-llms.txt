# Swish Analytics Sportsbook API

> Machine-learning sportsbook data API from Swish Analytics: player-prop pricing, pre-match and in-play match/team markets, bet-request (single and parlay) pricing, and results across NFL, NBA, MLB, NHL, NCAA basketball & football, ATP, WTA and soccer. Read-only JSON over HTTPS, authenticated with an ApiKey header.

Base URL: https://api.swishanalytics.com  |  Auth: `ApiKey` request header  |  Docs: https://docs.swishanalytics.com

## Key operations
- `GET /bet-request` — Bet-request (operationId: getBetRequest)
- `GET /nfl/players/props/inplay` — Nfl Players Props Inplay (operationId: getNflPlayersPropsInplay)
- `GET /mlb/matches/markets/prematch` — Mlb Matches Markets Prematch (operationId: getMlbMatchesMarketsPrematch)
- `GET /nba/players/props/inplay` — Nba Players Props Inplay (operationId: getNbaPlayersPropsInplay)
- `GET /bet-request/results` — Bet-request Results (operationId: getBetRequestResults)
